# Code map

CROWE-inspired H/V area/aspect family (2026-11-16, V2A): `design/generators/crowe_hv_area_aspect_v1.py` is a versioned FREEFORM generator (schema `crowe-hv-area-aspect-v1`) with exactly four search dimensions (`height_v_active_mm`, `L_forward_mm`, `area_mid_bias`, `aspect_timing_u50`). `width_h_active_mm`, `p_mouth` and `throat_round_hold_mm` are fixed generator-block values (hold default 0; a 20 mm A/B config exists). The aspect/exponent timing is a normalized C2 smootherstep with an exact half point `u50`; the area bias is a C3 compact window; `A = C(p) a b` and `R = a/b` hold exactly. The V2A addendum supersedes the 15-40 mm circular-hold rule. `design/generated.py` dispatches it and validates the four-variable box; `tools/geometry/crowe_hv_area_aspect_sections.py` prints the 0/5/10/20/40/60/100 mm cuts and `crowe_hv_area_aspect_jacobian.py` runs the T2 rank check. Evidence: `docs/evidence/CROWE_HV_AREA_ASPECT_V2A_2026-11-16.md`; research: `docs/research/typologies/CROWE_V2A_THROAT_TRANSITION_ADDENDUM_2026-11-16.md` (and the V2 document it supersedes).
