## Canonical gates

- `F_X` = the brief's `target.f0_hz`; `BAND_HI` = `min(8000, target.band_hi_hz)`.
- **H**: every solved f in [`F_X`, `BAND_HI`] has `|bw_h/coverage_h - 1| <= 0.2`.
- **V**: every solved f in [`max(1.5*F_X, f0_v)`, `BAND_HI`] has `0.6 <= bw_v/coverage_v <= 1.25`.
- **DI**: `max(di_db) - min(di_db)` over [`F_X`, `BAND_HI`] <= 5 dB.
- **BW8K**: at the highest solved f <= `BAND_HI`, `bw_h >= 0.75*coverage_h` and `bw_v >= 0.75*coverage_v`; if `BAND_HI` is not solved the top frequency below it is used and `top_below_band_hi` is flagged.
- **Loading**: LFP20 (Re z crossing 0.2 from below, log-f interpolated) must satisfy `LFP20 * 1.6 <= F_X`; Re z must stay >= 0.5 at every solved f >= `F_X`. A grid whose first sample is already above the threshold is resolved-low at the grid start.
- **Throat**: `throat_check.throat_shape` + `fits_exit` on the solved mesh; width/height within 0.5 mm of the driver exit diameter and roundness within 0.03 of 1.0. Missing/unreadable mesh is unresolved.
- **pass_all** = H and V and DI and BW8K and Loading and Throat. A gate with no evaluable sample/crossing/mesh is unresolved and FAILS.
