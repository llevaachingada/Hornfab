## 2. The plumbing (all offline-tested; fix-18's report)

- Brief schema: `brief.mounting` = `{type: enclosure (required), depth_mm > 0, margins_mm (scalar or
  {l,t,r,b}, each > 0, mesher default 25), edge_mm ≥ 0 (default 18), plan: "rounded_rectangle" (the
  ONLY token — the mesher refuses ellipse/superellipse on reduced/closed domains)}`; unknown keys
  refused; normalized block on `Config.mounting`; re-validated inside `load_config` when embedded.
- Translation = the MESHER'S OWN KEYS via one shared helper: formula route →
  `mcfg["mode"]="enclosure"` + top-level `mcfg["enclosure"] = {depth_mm, space_l/t/r/b_mm, edge_mm,
  plan_type: 1}` (exactly 7 keys; the mesher's own defaults fill the rest — no invented keys, no
  nesting under `mesh`). GRID route → the same helper → `HornEnclosure` dict with
  `outer_points=None` + `wall_thickness_mm=0` (structural guard: enclosure + outer shell is refused
  at the mesher's `PointGridHornGeometry`). CAD/STEP route → clean `GeometryInvalidError` (mounting
  explicitly deferred there).
- Cache identity: mesh/evaluate/solve/run-known keys append `-mnt-<12-hex>` of the normalized block
  (verified distinct on disk: `runs/m6_wp12`'s cache dirs); absent mounting = byte-for-bit keys.
- Echoes: `mesh_meta.json["mounting"]` (normalized + effective mesher keys + counts); ndjson
  `row["mounting"]` + the same key suffix; dataset record `provenance.mounting`. `export_step` also
  carries the mounting (an enclosure run exports the enclosure solid, never a silently freestanding part).
- `examples/briefs/enclosure_1in.yaml` (new): 1-inch 90×60 brief with the mounting block.
- Focused suites: mounting+config+brief-authoring **71/0/0**; the mesher-gated single quarter
  enclosure build **passed in 0.54 s** (1495 tris vs 1166 freestanding @3 kHz; tags include the
  ENCLOSURE group; `mesh_meta` echo verified).
