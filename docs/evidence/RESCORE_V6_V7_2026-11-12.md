# Objective v6 vs v7 offline re-score

Generated by `tools/rescore/rescore_v6_v7.py` from the committed dataset shards (`shard-*.jsonl` + `shard-NNNN/rec-NNNN.npz`). Zero GPU, zero solver: the stored metric arrays are re-scored, not re-solved. `dataset/` is never written.

## Method

- Each stored row keeps its OWN `target`; the brief supplies the version's weights + objective block.
- Rows are read with `gate_audit.parse_stored_row` (version-agnostic) and re-scored with `objective_v6` and `objective_v7`.
- Class A/B/C comes from the stored target: A = CD default, B = loading-scored (`z_min >= 0.5` or `di_slope_target >= 2`), C = low-reach (`f0 <= 500 Hz`).
- v6 has one shipped brief only (`native_lecleach_1200_1in_v6`, class B); it is applied to every class. v7 uses the class-matched hardened brief.
- Top-20 is unique by (design hash, target); ties/penalties sort last.
- Kendall tau is over every unique design scored under BOTH versions in the class.
- Gate counts use the canonical `gate_audit` definitions. The throat gate is **UNRESOLVED** for every row: the dataset stores no mesh, so `gate_pass_all_no_throat` excludes it.

during the evening). This re-score is therefore a **snapshot at run time**, not a census:

Reading: the two objectives do **not** rank the stored population together. All-design tau is
weakly positive (they share the pattern-shape signal), but on the shortlists themselves tau is
**negative** in every class — v6 and v7 disagree about which designs belong at the top. That is the
quantitative basis for the decided recommendation in
`docs/research/LOADING_OBJECTIVES_RECONCILED_2026-11.md`: keep v6 for the Le Cléac'h / rollback
class and v7 for CD briefs; do not merge them into a v8 tonight.

Caveat the numbers inherit: the v6 class-B brief (`native_lecleach_1200_1in_v6`) is the ONLY
shipped v6 brief, so it is applied to classes A and C too — those two v6 columns answer "what
would the Le Cléac'h scorer say about this CD / low-reach population", not "a v6 A/C brief". No
v6 A/C brief exists to run instead (documented in the method section; a brief-design question for
the owner, noted in NOTES_FOR_SENIOR.md).
