## Limitations

- Coverage is the current S0 catalog native cohort; the parent joins by design_hash. The R0 artifact embeds only its 50-row display subset while its counts report 200 scored rows, so offline_score status is attached only where the artifact exposes a design_hash.
- run_id is empty on every native catalog row; run provenance is recovered only by exact (design_hash, mesh_hash, solve_hash) match in run ndjson. A physical key found in multiple runs is reported as ambiguous, never assigned.
- Verify pairing is asserted only for rows whose verify ndjson exists in the same run as the screen counterpart. The dataset has no verify_of field; screen rows with no verify row stay 'no_verify_row'.
- There is no per-design B2 geometry-descriptor index; physical size uses stored design parameters (morph_width_mm, morph_height_mm, L_mm), which are nominal morph targets, not a measured mouth or an acoustic size law.
- Loading weight is 0: no loading, efficiency, distortion or maximum-SPL claims.
- Above f11 the uniform-piston source is a geometry comparison; the size/frequency confounding stays explicit and uncorrected.
