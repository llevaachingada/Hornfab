Read-only apart from this report and `inventory/I1_docs_top.csv`; no code/config/brief edits, no git

## Scope and method

- Inputs: `docs/*.md` at top level and repo-root `*.md`/`*.json`, excluding `AGENTS.md`, `CLAUDE.md`,
  `README*`, `CONTRIBUTING*`, `TOOLCHAIN*` and excluding `docs/INDEX.md`, `CODE_MAP.md`,
  `ACTIVE_STATE.md`, `CONTINUITY.md`, `ISSUES.md`.
- Filesystem has **53** `docs/*.md`, not the 54 the handoff states. After the 5 exclusions that is
  48 docs rows, plus 5 root `.md` and 6 root `.json` = **59 rows**.
- Titles are the files' H1 (non-ASCII punctuation normalised to ASCII); dates are from the filename or
  the first paragraph; one-liners come from the H1 and first paragraph only.
- `inbound_links` method: scanned all 2,290 `.md` files under the checkout except `.git`
  (tracked + untracked), parsed inline markdown links `](dest)`, resolved each destination relative to
  its containing file (case-insensitive, anchors stripped, `%xx` decoded, Windows separators
  normalised), and counted **distinct source files** that resolve to the target, excluding the target
  itself. External schemes and bare `#` anchors were ignored. `docs/INDEX.md`, `CODE_MAP.md`,
  `CONTINUITY.md` and `ISSUES.md` count as link *sources* even though they are excluded as rows.

## Inbound-link surprises

- **Four in-scope docs have 0 inbound links**: `docs/GUI_HANDOFF_2026-11-12.md`,
  `docs/SOLVE_CAMPAIGN_PLAN_2026-10-26.md`, `HANDOFF_2026-11-18.md` and `NOTES_FOR_SENIOR.md` (plus the
  six JSON files). `NOTES_FOR_SENIOR.md` is 0 only because files reference it in backticks, not as a
  markdown link; it is heavily used in prose.
- **`docs/INDEX.md` is effectively the only discovery surface.** 45 of the 53 docs/root rows have
  `inbound_links <= 1` (4 have 0, 41 have exactly 1), and the single link is almost always
  `docs/INDEX.md`. Remove or break INDEX and most of these docs become orphans. Only 8 rows have more
  than 1 inbound link.
- **Stale archive metadata.** `docs/archive/2026-11-14/README.md` says a batch (including
  `IMPLEMENTATION_PLAN_2026-11-12_DAY.md`, `SWARM_PLAN_2026-10-30.md`, `HANDOFF_NEXT_RUNS_2026-10-30.md`,
  `HANDOFF_COLLABORATOR_2026-10-27.md`, `GUI_HANDOFF_2026-11-12.md`, `OPENCODE_HANDOFF_2026-11-12.md`,
