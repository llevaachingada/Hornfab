  not the newest file in its folder, so it is not a CSV row. It should be linked from the research
  README separately.

  `TEST_SUITE_OPTIMIZATION` are both retained because the newer document supersedes only the
  former's next step, not its R1–R8 findings.
- No selected document was classified `negative-result` except the driver-shortlist audit. Several
  docs contain rejected sub-hypotheses (for example unusable salmon `x_amp` bounds and the rejected
  data-driven v4 tolerances), but their primary purpose is not a rejected hypothesis, so marking
  the whole file negative would misstate it.
