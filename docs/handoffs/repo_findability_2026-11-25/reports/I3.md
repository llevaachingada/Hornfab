# I3 — evidence inventory

Workstream I3 of `docs/handoffs/REPO_FINDABILITY_HANDOFF_2026-11-25.md`. Two new files only:

- `docs/handoffs/repo_findability_2026-11-25/inventory/I3_evidence.csv` (159 rows: 1 header + 47 evidence + 112 queue, plus a 70-row loose-doc addendum — 229 data rows total)
- this report

Method: one representative doc per evidence folder (`README.md`, else `PREDECLARED*`, else
`COMPLETION*`, else newest `.md`); data-only folders were read from their summary JSON/CSV or the
linked top-level evidence doc. `linked_from_INDEX` is a markdown-link check
(`](...evidence/<folder>...)`) against `docs/INDEX.md`; a plain code-path mention does not count.
Queue files are matched by topic and date; an unmatched file gets its own row.
No GPU, no queue/config/brief edit, no commit.
