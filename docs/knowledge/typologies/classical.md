# Classical profiles: conical, exponential, tractrix

- **Principle:** Conical walls expand linearly in radius; exponential profiles use an exponential area expansion; tractrix profiles follow a different geometric construction. These are profile families, not interchangeable descriptions of a complete horn.
- **Useful objectives:** Choose the band, loading, response smoothness, directivity, size and termination to suit the use. Compare complete designs under the same source and mounting assumptions.
- **Limits / wrong assumptions:** An idealized one-dimensional profile does not fully predict finite-mouth radiation, reflections or off-axis behavior. A profile name does not guarantee a particular sound or coverage. No universal Keele/CD target is implied.
