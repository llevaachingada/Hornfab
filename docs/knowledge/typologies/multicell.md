# Multicell

- **Principle:** Multiple separated horn cells radiate in different directions from a shared manifold; cell arrangement and septa are part of the acoustic geometry.
- **Useful objectives:** Study combined polar coverage, interference, response and loading across the intended band, including the actual cell arrangement, source and mounting.
- **Limits / wrong assumptions:** Cells are not independent far-field beams that can simply be added without phase effects. Thin septa and close opposing faces challenge mesh and numerical quadrature; compare independently validated solves before trusting a result. The dossier records unresolved physics troubleshooting. No universal Keele/CD target is implied.
