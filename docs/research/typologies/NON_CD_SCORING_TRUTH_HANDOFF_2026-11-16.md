# HornFab acoustic scoring truth and non-constant-directivity correction
**Agent handoff, 2026-11-16. Source-reviewed against published `llevaachingada/Hornfab` main at commit `2c0e2928e932a47975fc284401eafa74ebfc5002`.**

## Mission and design decision
Do not implement the prior GUI-only handoff as a complete fix. It accurately identifies that the current scoring system has no sloped H/V beamwidth target, but its derived sloped GUI curve is NOT scored and is NOT uniquely implied by the DI slope. Correct the GUI to display present scoring truth first, then design an explicit opt-in non-CD objective profile that permits controlled, smoothly narrowing coverage without forcing CD behavior. Preserve existing production scoring semantics, saved responses, and running jobs.

**User intent:** HornFab should optimize CD-oriented waveguides for stable pattern where appropriate, while optimizing JMLC/Le Cléac'h, certain exponential/tractrix/spiral/rolled/longform horns and non-CD hybrids for excellent loading, smooth frequency/polar behavior, listening-window suitability, controlled narrowing and an acceptable HF coverage floor. A non-CD horn should NOT be made worse merely because it is not CD. This does not mean deliberately reward uncontrollable narrowing. Do not classify solely on a family name.

The previous GUI agent's illustrative Gaussian-derived 8k curve 43.5 x 27.2 would violate that floor. Both the flat coverage and floor penalties still apply. Display-only hypothetical lines must not be presented as scored truth.

`distd` is an important logical mismatch: a perfectly monotonic straight DI rise of +5 dB/dec has slope loss 0 yet std(DI)>0, so its distd loss remains positive. The brief header's statement that more `distd` penalizes "lumpy/jumpy DI" is mathematically false. Correct this through a new, separately versioned residual/roughness metric, NEVER by silently redefining existing v7 `distd`.

## Acoustic taxonomy, with exceptions
1. **CD-oriented**: Keele/JBL original Bi-Radial is explicitly a constant-directivity invention (US4308932A); ATH OSSE/R-OSSE and CD-throat hybrids may also be targeted at stable coverage. For these, flat H/V coverage with smooth polar and loading objectives makes sense where aperture/source can support it. Their *actual* constancy is not guaranteed just by geometry label.
2. **Smooth narrowing / loading-first**: JMLC/Le Cléac'h, some Iwata/longform, tractrix/exponential, Joseph Crowe ES-spiral biradials, certain rolled horns and specific hybrids. Desirable properties include effective loading, smooth gently narrowing radiation into the presence band, no lobes/nulls, usable seat coverage and a responsible high-frequency minimum coverage. Different constructions and driver/baffle assumptions matter.
3. **Research hybrids / undecided**: biradial ES-mouth variants, mixed-profile/OSSE hybrids, superellipse or Lamé interpretations. The intended objective should be an explicit YAML choice after examining actual solved polars and design purpose; the word "biradial" alone cannot pick CD vs narrowing.
4. **MEH**: use synthesized *system* radiation and phase/crossover, with separate objective family; do not blindly apply single-source horn-only targets.

Primary references: Keele's [US4308932A patent](https://patents.google.com/patent/US4308932A/en) and [inventor's patent list](https://dbkeele.com/awards-and-recognition/); Crowe's [ES-290 narrowing profile](https://josephcrowe.com/products/es-290-biradial-wood-horn), [ES-800 CD comparator](https://josephcrowe.com/blogs/news/es-800-biradial-wood-horn); Le Cléac'h [ETF 2010 Horn Profiles](https://pearl-hifi.com/06_Lit_Archive/14_Books_Tech_Papers/LeCleac%27h_Jean-Michel/Horn_Profiles.pdf); [Sridhar et al AES 2016 constant-directivity metrics](https://aes.org/publications/elibrary/elibrary-page/?id=18200). The AES paper explicitly makes std(DI) a metric for **constant** directivity. It is NOT a smooth-trend metric when nonzero slope is intended.

## Priority P1: actually score non-CD intended shape, opt-in, versioned
Design a narrowly scoped, independently versioned objective/config capability (new objective version or explicit compatible opt-in under a new identity). Do not mutate v6/v7 historical score semantics. Scored H/V profile must be a first-class input, NOT reverse-engineered from DI. Proposal:
```
target:
  coverage_profile:
    mode: frequency_envelope
    interpolation: log_frequency
    h:  # anchors are deliberate, validated acoustic preferences, not automatic geometry guarantees
      - {hz: <f1>, preferred_deg: <H1>, min_deg: <Hmin1>, max_deg: <Hmax1>}
      - {hz: <f2>, preferred_deg: <H2>, min_deg: <Hmin2>, max_deg: <Hmax2>}
    v:
      - {hz: <f1>, preferred_deg: <V1>, min_deg: <Vmin1>, max_deg: <Vmax1>}
      - {hz: <f2>, preferred_deg: <V2>, min_deg: <Vmin2>, max_deg: <Vmax2>}
  profile_mode: smooth_narrowing
```
This is **illustrative proposed schema**, not current supported YAML. Design validation, sensible bands, per-plane f0, one-sided low-frequency behavior and score weighting are essential. Prefer a *feasible envelope* or soft corridor to forcing every JMLC profile onto one exact arbitrary curve; make constant mode the exact old behavior. Separate absolute seat-coverage minimum and 8k-floor settings from an H/V target's arbitrary coefficient. Establish HF minimum from product listening geometry and real polars, not 0.75 times a flat 700Hz target. Retain current `dislope` if scientifically justified, but do not treat one +5 dB/dec number as universal preference. Include loading and off-axis smoothness.

**Correct DI shape smoothness:** add `di_roughness = std(DI - fitted[a+b log10(f)])` or other validated residual-based statistic, using the exact frequency/weight policy. Do not call raw `std(DI)` a bump/roughness metric. Allow independent target slope with transparent weights and tolerance. This is a new term/new identity so old J reproduction remains exact.

**Correct ancillary terms:** Rework target-dependent ripple window, diagonal reference and any signed V and beamwidth floor or feasibility check to use this same frequency-dependent H/V profile if applicable. If no defensible diagonal target exists for the non-CD morphology, disable the old target-centred `diag` penalty in new non-CD briefs pending a better full-pattern diagnostic; continue reporting measured diagonal response and multilobe flags. Do not confuse natural diagonal behavior of rectangular horns with a discontinuity or a severe off-axis null. Support angle-specific pattern smoothness and cross-frequency polar consistency after removing EXPECTED narrowing, preferably using full balloon where present; never invent high-frequency source behavior.

**Feasibility realism:** with a 600W x 480H mouth and target 80H x 50V to 700Hz, empirical Keele sizing predicts ~496 mm horizontal aperture and ~794 mm vertical aperture for the desired CD control. Thus strict 50° vertical at 700Hz is likely physically unattainable for a stand-alone 480mm-tall horn, though actual baffle and complex profile can alter onset. Do not hide that conflict in J. Derive independent `f0_h`, `f0_v` from tested physics/mounting, or allow appropriate low-frequency widening. This applies even to CD-oriented briefs.
