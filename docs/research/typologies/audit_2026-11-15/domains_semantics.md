# Parameter semantics and activity

The per-configuration rows and values are in `domains_current.csv` and `.json`. The extractor uses the repository's `_load_yaml_extends` deep merge, so moderate and strong original rect configs inherit the three searched base bounds; their pucker amplitudes are fixed. Row `note` distinguishes inherited versus declared/overridden inputs and identified resolver defaults. Child and parent YAML bytes must both be retained: the child SHA alone does not identify the inherited recipe. Brief driver rows come from each referenced or embedded brief; an absent brief is explicitly unresolved, not assumed. Runtime `--brief`, embedded-run semantics, or concurrent file edits can change the resolved values. This is a source-derived inventory, not a complete list of all transitive installed-mesher defaults. Where a default is not traced, it is not presented as resolved.

| Key(s) | Meaning and activity / coupling |
|---|---|
| `r0_mm`, `a0_deg` | OSSE wall starting radius and tangent half-angle. A fresh brief normally pins `r0` to driver; `a0` is pinned only when brief policy says so. With positive extended throat, `r0=driver radius + extension length*tan(extension angle)` and `a0=extension angle` per evaluation. Embedded historical brief skips fresh pins (`config.py:1185-1244`, `search/evaluate.py:367-383`). Thus stored seed values are not separate effective freedoms in the extension route. |
| `a_deg`, `az_a_cos_amp`, `az_a_cos_pow` | OSSE base far-wall half-angle plus azimuth cosine amplitude and exponent. Amplitude is degrees; exponent has no geometric effect if amplitude zero. Physical directivity is not asserted. |
| `az_a_sf_amp`, `az_sf_m/n1/n2/n3/a/b` | Superformula azimuth wall-angle amplitude and its shape coefficients; all shape coefficients are dormant for this wall-angle term at zero amplitude. `az_n_cos2_amp` and `az_s_cos2_amp` alter OSSE n and s by azimuth, respectively (`design/families.py:100-110, 134-166`). |
| `L_mm`, `n`, `s`, `q`, `k` for OSSE | Axial length, termination superellipse exponent, termination amplitude, normalized termination saturation and base-law shape. `n` and `q` affect the termination term only when `s` is nonzero; `k` shapes the throat-to-wall law. This statement is family-specific (`design/params/knobs_native.py`, `design/families.py`). |
| `s1`, `s2` | Throat stretch in `x + s1*degrees(atan(s2*x))`, units mm/deg and 1/mm. Both must be nonzero for stretch. `exponent` and `aspect_ratio` select base cross-section; both are fixed in these native seeds. `slot_length_mm` selects an extended slot when nonzero. |
| `morph_target`, `morph_width_mm`, `morph_height_mm`, `morph_corner_mm`, `morph_exponent`, `morph_rate`, `morph_fixed`, `morph_allow_shrinkage` | Target 0 disables all the target's shape and progression fields; 1 rectangle, 2 circle, 3 superellipse. Width/height are full dimensions, zero means infer. Corner applies to rectangle; exponent to target 3. Rate and fixed specify progression; allow-shrinkage governs inward morph. Values remain in recipe even when dormant. The mesher may clamp corner or exponent (`design/params/knobs_native.py:370-475`). |
| `h_a_deg/v_a_deg`, `h_n/v_n`, `h_rm_mm/v_rm_mm`, `L_mm` in biradial | Plane initial wall angle, power exponent, mouth half-width/height and common length in `r=r0+tan(a)z+c*z^n`; c is derived to satisfy mouth size, so values are geometrically coupled (`design/generators/registry.py:51-57, 210-217`). Blend length zero disables throat blending; 25 mm fixed in the biradial seed. H/V blends and driver matching interact. |
| `h_T/v_T`, `h_rm_mm/v_rm_mm`, `L_mm` in hypex | Plane hyperbolic profile parameter, plane mouth radius and common depth; T=1 is exponential limit. `mouth_corner_mm` defines rounded rectangle corners, while `mouth_exponent` applies to superellipse; other outline laws do not use them. |
| `g_width_mm/g_height_mm/g_depth_mm`, `g_depth_h_ratio`, `g_decay` in rect | Nominal H/V dimensions and vertical depth scale; H development is relative through `depth_h_ratio`; `decay` is exponent b of reference integrals `exp(-b*t)*(cos(t),sin(t))`. Finished shell extents and cross-plane profiles are coupled (`tools/geometry/rolled_rect.py:35-44, 79-110`). |
| `g_rect_exponent`, `g_rect_turn_deg`, `g_throat_turn_deg`, `g_terminal_deg` | Rectangle transition superellipse exponent and turn at which it develops; throat transition turn; terminal reference-curve turn. They are mathematical curve parameters, not a measured acoustic wrap angle. Native rect uses the corresponding private versioned kernel. |
| `g_pucker_h_mm/v_mm`, `g_pucker_start_deg` in original rect | H/V weighted axial displacement amplitudes with cos(4 psi) and smooth start window; start has no displacement effect at zero amplitudes. It changes z, not the x/y outline (`rolled_rect.py:79-110`). This is distinct from native radial relief. |
| `g_h_depth_scale`, `g_crown_mm`, `g_junction_power`, `g_throat_blend_mm` in section | Horizontal reference depth scaling relative to vertical; transverse crown amount; smooth intersection power; source matching axial length. Width/height/depth scale digitized reference sections. The crown and intersection change joined surface and reconstructed body, not just appearance (`tools/geometry/crowe_panel.py:49-100`). |
| section `g_pucker_h_mm/v_mm`, `g_pucker_start_s/peak_s/end_s` | H/V weighted nonnegative amplitudes generate angularly signed axial relief with a smooth finite station window; its window positions are dormant at both amplitudes zero. The actual valid range and throat/body attachment depend on the other shape values (`section_pucker.py:15-55, 75`). |
| `g_inward_h_mm/v_mm`, `g_axial_h_mm/v_mm`, `g_relief_start_s/peak_s/end_s` | Native family inward radial and signed axial amplitudes with independently named H/V weights, shared station window. A selected mode disallows nonzero inactive amplitudes; window positions change nothing at zero active amplitudes. Geometry validity and full body depend on combinations (`rolled_family.py:94-117, 120-190`). |
| `g_fc_hz`, `g_T`, `g_stop_deg`, `g_ar_m`, `g_ar_p` | Iwata aspect-stretch reconstruction: Le Cléac'h march cutoff parameter, T, terminal curve parameter, mouth aspect ratio and axial aspect progression exponent. Circular throat aspect is fixed; these jointly set dimensions and curve, and `g_stop_deg` is not an independently measured physical lip angle (`grid.py:241-260, 1700-1731`). |
| `g_a_h_deg/v_deg`, `g_k`, `g_L_mm`, `g_s/n/q`, `g_r_lip_mm`, `g_wrap_deg` in Crowe-X | Per-azimuth interpolated OSSE wall half-angles and base/termination parameters, with inferred curled-lip radius and curve parameter. Fixed/default fold, union and ripple determine whether extra angular terms are active. `g_sf_m/n1/n2/ab/amt/start` control the superformula factor and onset; shape controls are dormant at zero `g_sf_amt` (`grid.py:1734-1753`). |
| `g_width_mm`, `g_height_mm`, `g_rect_exponent`, `g_a_h_deg/v_deg/diag_deg`, `g_k/r/m/b/q/tmax` in R-OSSE rect | Superellipse mouth dimensions/exponent; H/V/diagonal half-angle law; OS throat factor; dimensionless axial rounding/shoulder/quadratic weight, throat-to-mouth blend exponent and terminal coordinate. `r` is not mm, `b=0` removes the secondary term, and depth is derived (`tools/geometry/rosse_rect.py:75-110`; `design/params/knobs_native.py:956-990`). |
| `generator.*`, `brief.driver.*` | Fixed categorical route/mode, sampling counts, span, thickness, driver radius/angle and source-related context. They are recipe/geometry identity inputs, not CMA dimensions. Identified omitted defaults are tagged as such; `seed_policy` controls config loading rather than geometry (`registry.py:244-245`). |
