and unification."* That condition is met. Per handoff §9.1 the threshold is not moved. This agent's
recommendation:

   existing families"). The seven U3 structural freedoms — vertical timing, termination splits,
   section steering, diagonal pull — become **per-lane modules on the existing specialists**, not a

3. **Optional predeclared falsification test — U1-bis (CPU-only, ~1 day, not run):** justified by

   and 30° radii simultaneously — measured, 48 mm overshoot at the p=16 clip). Redesign:
   two-exponent or corner-radius section law, curvature-placed ψ knots, per-plane depth law. Pass:
   ≤ 0.5 mm on ≥ 3 lanes. If it passes, the unified argument reopens and B3 (22 solves) returns; if
   not, closed permanently. Proposed to run before any solve money.

### 2.2 Scoring — the most consequential open item, and it is a family-selection decision

- `A9` settled the decomposition: term-set change and corridor are both first-order and do
  different things — the term set reshuffles within lanes (6/20 survive), the corridor changes
  *which family leads* (`ext_throat_hvlaw` 1st → 4th; `osse_rrect_fold_warm` leads).
- `FABLE_DISCOVERY.md` F2 is a physics fact: **the 80×50 point brief is partly unreachable in the
  600×480 envelope** — V beamwidth at 700–1,100 Hz never drops below 66° against a 50° target
  (Keele aperture heuristic ≈ 1 kHz for 480 mm). A point target there penalizes all designs
  (`OPTIMIZATION_AND_BRIEF_AUDIT.md` shows v7 scores that unreachable point at every frequency).
- Grid: `N3` — J_v9 converges at 58 dense points (sd 0.032/0.019); **with constancy it needs 116**
  (0.055/0.014); residual from 18 solved frequencies 0.113 at the top, carried by `flat_cv`, `load`,
  `flat`. `R2`: solve ≥ 22 frequencies; the rational-pressure interpolant is unusable.
- Owner decisions C1–C4 remain open (see `OWNER_DECISIONS_2026-11-17.md`, options only). Below
  ~0.13 J, ranking differences are not decisions.

### 2.3 Search, predictor, supervisor — shrink the model layer

- **Do not wire any predictor hook.** A fails (0.733 vs 0.8; 1 of 5 true top lanes), B fails
  (11/19 vs 13/19; equals one random design), C's wins belong to the pool (random beats the
  predictor 10/12/10), skip test 8.9 % vs < 2 % (`P1_PREDICTOR_REPLAY.md`).
- **The dataset cannot fairly test the predictor:** zero strict unbiased designs anywhere. Any

  refusals — they are excluded from training (`OPTIMIZER_AND_SWITCH_SECTION.md`, citing

## 3. Truth fixes — stage-0 proposals, no solves, and the real bottleneck

The binding constraint in the current window is **geometry/envelope, not GPU**: 88.6 % of attempts
reach a full solve and `mesh_too_large` is 0 (`FAILURE_AND_BOUNDARY_AUDIT.md`), but three provenance
incidents and a conservative refusal are live:

1. **Provenance rule.** Three incidents: Klangfilm `e3a1f4a3…` (72 designs, kernel not in git
   history), lecleach (`d6c9abd` changed geometry after both runs, no digest), ROSSE (`a10e784` —
   a validator-only change that locked 11 stored designs out of their own adapter until bypassed in
   memory). Proposal: **store the implementation digest split kernel-vs-validator, or hash the
   generated point grid itself**, and require it on every recipe.
2. **Envelope convention (owner decision):** stored box = meshed inner-sheet box (70/70); the
   generator's outward `outer_points` shell is not in the mesh. Proposal: envelope = the mesh-built
   inner sheet; outer array kept as a trim envelope. `X1B`: biradial's +1.9…+3.5 mm fully
   explained; **0/309** stored designs near a limit.
3. **Failure taxonomy:** post-mesh envelope violations coded as `invalid_geometry`; the
   `invalid_envelope` prefix mapping bug; `search.links` raises for generator families
   (`FAILURE_AND_BOUNDARY_AUDIT.md`).
4. **Conservative GRID extent** refuses candidates the mesh would pass; realised false refusals
   never measured (E-018) — cheap test T4.
5. **Metadata schema:** ATH wall thickness, termination kind for native lanes, resolved source-cap
   values exist nowhere — recipe schema v2.
6. **Code truths for the owner's lane** (this agent implements none of them): v4-only cohort gate
   vs production v7 (E-041); `flat` ddof=2 vs `flat_cv` ddof=0 undocumented (E-044); `mode`
   enclosure-overwrite hazard (E-012); `budget_counts` doc mismatch (E-055); night-runner
   idempotency is per-process so a restart can double-run finished jobs (`SEARCH_CONTROL_MAP.md`);
   watchdog `best_J` is null in all 38 stops and must be recomputed from `search.ndjson`.
