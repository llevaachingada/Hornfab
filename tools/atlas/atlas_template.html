Decision map

Which search lines to lean into

One dot per search line (one typology config on one brief, all its seeds together), current objective versions only. Across: total solves. Up: how much its latest run was still improving in its last 20% of budget. Dot size is compute hours.

Method

How this page is built

Read-only over every run folder: run.json and search.ndjson, inline verify/ rows, and Bayesian study-*/screen. A solve is a non-cached row with ok and a real J; a refusal is any non-ok row. A search line is one config name with any seed suffix removed, on one brief and objective version.
